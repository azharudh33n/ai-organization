Why teams use it

Right-sized, not bloated

Solo, Squad or Company tier, chosen before anyone is hired. A README fix stays a one-person job.

Separation of duties

Whoever builds a deliverable never grades it. Benchmarks, acceptance tests, reviews and fact-checks go to someone else.

Karpathy's operating system

Think before acting, simplicity first, surgical changes, and checks that pass or fail. A locked-eval loop handles any metric goal.

CI/CD sized to the project

A lean baseline for every project. Merge queues, OIDC, provenance, staging and canary releases only when the stakes call for them.

Independent QA

A fresh agent that never saw the build checks every Definition of Done item and records evidence.

Token-efficient

About 2,000 tokens on trigger. Playbooks load only for the departments you staff.

How it works

  1. Size the job: Solo, Squad or Company.
  2. Brief and Definition of Done: 5–10 criteria, each a test, metric or inspection.
  3. Org chart: the smallest team that covers the DoD without letting builders grade their own work.
  4. Talent sourcing: skills come from your repo's roster or skills.sh, pass an independent-audit vetting gate, and are installed pinned to a commit so cloud sessions start with them.
  5. Hiring: one tight job brief per subagent, with handoffs of 200 words or less.
  6. Plan and execute: rolling-wave plan, parallel lanes, CI/CD before features.
  7. Independent QA: evidence for every DoD item.
  8. Review, delivery and retro: you approve anything irreversible before it happens.

FAQ

What is a Claude Code skill?

A folder with a SKILL.md file that Claude loads when a task matches its description, following the open Agent Skills specification. ai-organization is a skill packaged as a Claude Code plugin.

How is it different from just using subagents?

Subagents are the workers. ai-organization is the management layer: how many to hire, what each may touch, which skills they load, and what evidence counts as done.

Does it work without subagents?

Yes. Claude plays each role in sequence and keeps the same briefs and quality gates.

Will it use a lot of tokens?

No. Small jobs skip the ceremony, playbooks load on demand, and plans are detailed one milestone at a time.
